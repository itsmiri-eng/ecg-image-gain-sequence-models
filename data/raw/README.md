# Raw data references

The original datasets remain in their original directories; no large copies were made.

- `../../ecg files/`: source ECG JPEGs used by the current image experiments.
- `../../mendely images.zip`: original archive retained for provenance, not an additional training dataset.
- `../../ptb-xl-a-large-publicly-available-electrocardiography-dataset-1.0.3/`: separate waveform dataset, not mixed into these image experiments.

Printed report IDs are present in the ECG images. Local identity audit files are excluded from Git. These IDs have not been validated as patient identifiers.
